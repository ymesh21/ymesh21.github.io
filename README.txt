YOHANNES MESHESHA PORTFOLIO
============================

Files
-----
- index.html: page content and section structure
- style.css: all custom visual styles (separate stylesheet)
- script.js: theme switcher, mobile navigation behavior, scroll state, and back-to-top
- assets/profile-placeholder.svg: fallback if the Google Drive portrait cannot load
- assets/Yohannes_Meshesha_CV.pdf: place your current CV PDF here

Run locally
-----------
1. Keep index.html, style.css, and script.js in the same folder.
2. Create an assets folder.
3. Put your CV PDF at assets/Yohannes_Meshesha_CV.pdf.
4. Open index.html in a browser. Internet access is required for Bootstrap and Google Fonts CDNs.

Before publishing
-----------------
- Confirm the Google Drive portrait is shared for public viewing; otherwise replace its URL in index.html with a direct, public image URL or assets/profile.jpg.
- Replace the LinkedIn and GitHub links in index.html with your actual profile URLs.
- Confirm all certificate titles, issuers, and dates against your certificates.
- Project cards currently describe project concepts/portfolio summaries. Add only accurate details, authorized screenshots, and working demo/repository links.
- Add a real CV PDF to assets/Yohannes_Meshesha_CV.pdf; the Download CV button expects that file.
- Add assets/favicon.png or remove the favicon link if you do not have one.

The page uses Bootstrap 5.3.8 from the official CDN and a separate custom style.css file.
